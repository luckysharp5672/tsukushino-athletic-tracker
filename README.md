# つくし野アスレチック 攻略記録

つくし野アスレチック 50コースの制覇記録を管理するWebアプリケーションです。

## 機能

- **チェックボックス管理** — 50コース各々のクリア状況を記録
- **チャレンジ日ごと管理** — 複数回のチャレンジを別々に記録可能
- **自動リセット** — チャレンジ日を変更するとチェックが自動でリセット
- **過去の記録復元** — 過去のチャレンジ日を選択して当時の状況を復元
- **Google Sheets連携** — GASを通じてSpreadsheetに自動保存

## 使い方

1. **チャレンジ日を入力** — 「今回のチャレンジ」に日付を入力
2. **コースをチェック** — クリアしたコースにチェックを入れる
3. **自動保存** — チェック時に自動でSpreadsheetに記録される
4. **過去の記録を復元** — 「過去の記録を読み込む」からチャレンジ日を選択して「反映する」

## 備考

- GAS_URLが正しく設定されている必要があります
- Google Spreadsheetがアクセス可能である必要があります
